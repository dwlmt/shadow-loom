## 6. How to accept this CLA

You accept this Agreement in any of the following ways, all of which
are equivalent:

1. **DCO sign-off.** Adding a `Signed-off-by:` trailer to each commit
   (`git commit -s`) under the
   [Developer Certificate of Origin v1.1](https://developercertificate.org/),
   together with submitting the commit to this repository, constitutes
   acceptance of this Agreement for that commit.
2. **CLA-bot acknowledgement.** If a CLA-assistant bot is enabled on
   the repository, clicking the acceptance link on Your first pull
   request constitutes acceptance for all subsequent contributions
   from the same GitHub account.
3. **Signed copy.** For corporate contributions or where Your
   employer requires a signed paper trail, email a signed copy of
   this Agreement to `david.wilmot@gmail.com` with the subject
   `Shadow Loom — Corporate CLA`.
